**Source:** NeetCode's own public data (`neetcode-gh/leetcode` repo `.problemSiteData.json`) for problem list/category/difficulty, cross-checked against LeetCode's official topic-tag database (zero difficulty conflicts across 143 matched problems). Grouped by category in the same order NeetCode presents them on [neetcode.io/practice/practice/neetcode150](https://neetcode.io/practice/practice/neetcode150).
